# Video 40: Methods

A method is a function inside a class. We call it with a dot, and Python passes the object in as `self`.

| File | What it shows |
|---|---|
| [1_no_method_error.py](1_no_method_error.py) | Calling a method the class doesn't have (AttributeError). |
| [2_describe_method.py](2_describe_method.py) | A `describe` method, called on two pets. |
| [3_forget_self_error.py](3_forget_self_error.py) | A method without `self` (TypeError). |

Run a file from this folder:

```
python 1_no_method_error.py
```
