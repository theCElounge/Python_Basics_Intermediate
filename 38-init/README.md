# Video 38: `__init__`

`__init__` is the setup function Python runs for every new object, and it receives the values we pass to `Pet()`.

| File | What it shows |
|---|---|
| [1_arguments_error.py](1_arguments_error.py) | Passing a name to a class that can't take it (TypeError). |
| [2_init_runs_by_itself.py](2_init_runs_by_itself.py) | `__init__` runs by itself for every new object. |
| [3_passing_a_name.py](3_passing_a_name.py) | `__init__` receives the name we pass to `Pet()`. |

Run a file from this folder:

```
python 1_arguments_error.py
```
