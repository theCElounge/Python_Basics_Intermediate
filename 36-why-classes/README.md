# Video 36: Why classes?

Keeping each pet's data in separate variables, or passing a dictionary to a function, gets messy fast. A class keeps a pet's data and the functions that use it together.

| File | What it shows |
|---|---|
| [1_variables.py](1_variables.py) | One pair of variables for every pet. |
| [2_dictionary_error.py](2_dictionary_error.py) | A dictionary and a function, called without the pet (TypeError). |
| [3_class_and_objects.py](3_class_and_objects.py) | A Pet class, and two pet objects made from it. |

Run a file from this folder:

```
python 1_variables.py
```
