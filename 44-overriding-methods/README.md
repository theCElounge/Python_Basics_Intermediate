# Video 44: Overriding methods

A child class can override a parent's method by defining a method with the same name.

| File | What it shows |
|---|---|
| [1_inherited_speak.py](1_inherited_speak.py) | Dog uses Pet's `speak`. |
| [2_dog_and_cat_override.py](2_dog_and_cat_override.py) | Dog and Cat each override `speak`. |

Run a file from this folder:

```
python 1_inherited_speak.py
```
