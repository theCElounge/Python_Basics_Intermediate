# Python Basics: Classes and Objects

Short, runnable programs for the classes and objects videos (videos 36 to 45) of a beginner Python series.
Each folder holds the code from one video, split into small steps in the same order as the video.

## How to run

You need Python 3.12 or newer. Open a terminal in a video's folder and run a file, for example:

```
cd 38-init
python 2_init_runs_by_itself.py
```

On some computers the command is `python3` instead of `python`.

Each file ends with a comment that shows its output. Files whose names end in `_error` stop with an error
on purpose: they show the mistake from the video, and another file in the folder shows the fix.
